# 2. Introduction

## 2.1 Purpose

This document defines the functional and non-functional requirements for the Karate Clubs Management System (KCMS).

It serves as the primary reference for stakeholders, software architects, developers, testers, and future maintainers throughout the software development lifecycle.

---

## 2.2 Product Description

Karate Clubs Management System (KCMS) is a multi-tenant Software as a Service (SaaS) platform designed to help karate clubs and sports academies manage players, monthly memberships, branches, championships, belt examinations, and official federation documents.

The platform centralizes club operations while maintaining complete data isolation between tenants.

The first release focuses exclusively on karate clubs while keeping the architecture extensible for future support of additional sports.

---

## 2.3 Objectives

The system aims to:

- Digitize player management.
- Simplify monthly membership management.
- Reduce manual paperwork.
- Reduce registration errors.
- Simplify federation document generation.
- Improve operational efficiency.
- Centralize player information.
- Support long-term business scalability.

---

## 2.4 Intended Audience

This document is intended for:

- Product Owner
- Business Analyst
- Software Architect
- Backend Developers
- Frontend Developers
- QA Engineers
- DevOps Engineers

# 6. Project Scope

## 6.1 In Scope

The first release of KCMS shall provide the following capabilities.

### Platform Management

- Manage clubs.
- Manage club branches.
- Manage platform users.
- Manage subscription plans.
- Manage club subscriptions.
- Manage platform settings.

### Club Management

- Manage club information.
- Manage branch information.
- Manage club users.
- Manage permissions.

### Player Management

- Register players manually.
- Update player information.
- Archive player records.
- Search players.
- Upload player documents.
- Maintain player history.

### Membership Management

- Create membership plans.
- Assign memberships to players.
- Renew memberships.
- Suspend memberships.
- Record monthly payments.
- Track overdue memberships.
- View payment history.

### Player Transfers

- Transfer players between clubs.
- Transfer players between branches.
- Preserve transfer history.

### PDF Import

- Import federation player lists.
- Preview imported data.
- Validate imported records.
- Import approved records.

### Championships

- Create championships.
- Register participants.
- Generate championship sheets.

### Belt Examinations

- Create examination events.
- Register participants.
- Generate examination sheets.

### Document Generation

- Individual registration form.
- Collective registration sheet.
- Championship sheet.
- Examination sheet.
- Other federation documents.

### Reports

- Player reports.
- Membership reports.
- Financial summaries.
- Championship reports.
- Examination reports.

---

## 6.2 Out of Scope

The following features are not included in Version 1.

- Mobile applications.
- Online payment gateways.
- Federation administration.
- Match scheduling.
- Referee management.
- Tournament brackets.
- Attendance management.
- Inventory management.
- Accounting system.
- Public player portal.

---

## 6.3 Future Scope

The following features may be included in future releases.

- Support for additional sports.
- Mobile applications.
- Parent portal.
- Player portal.
- QR Code membership cards.
- Federation API integration.
- AI-assisted PDF extraction.
- SMS notifications.
- WhatsApp notifications.
- Online payments.
